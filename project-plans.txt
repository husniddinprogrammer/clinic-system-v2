Next.js + TypeScript + Tailwind CSS + PostgreSQL + Prisma yordamida Windows kompyuterda offline/local network rejimida ishlaydigan Doctor/Dentist Management System yarat.

Asosiy maqsad: Excel faylda hozir yuritilayotgan bemorlar hisobini zamonaviy web application ko'rinishiga o'tkazish. Dastur oddiy, tezkor, foydalanishga qulay va professional bo‘lsin. Ortiqcha funksiyalar, keraksiz modullar va murakkab UI qo‘shilmasin.

========================
TECHNOLOGY
==========

* Next.js
* TypeScript
* Tailwind CSS
* PostgreSQL
* Prisma ORM

Next.js:

* App Router
* Server Components'dan imkon qadar foydalanish
* Kerak bo‘lgan joylarda Client Components
* Route Handlers / Server Actions orqali backend logic
* Production uchun local/self-hosted ishlashga mos arxitektura

Frontend:

* React
* TypeScript
* Tailwind CSS

Database:

* PostgreSQL
* Prisma ORM

Authentication:

* Secure session/cookie-based authentication
* Password hashing

1. LOGIN VA USER SYSTEM
   ========================

* Password

* id

* password_hash

* role

* created_at

15. LOCAL / OFFLINE DEPLOYMENT
==============================

Dastur internetga bog‘liq bo‘lmasin.

Architecture local/self-hosted ishlashga mos bo‘lsin.

Single PC:

Browser
↓
Next.js local server
↓
PostgreSQL

LAN:

Doctor PC
Nurse PC
Admin PC
↓
Local Network
↓
Next.js Server
↓
PostgreSQL

Production deployment uchun Next.js local serverda ishlashi kerak.

Development rejimida:

npm run dev

Production rejimida:

npm run build
npm run start

yoki mos production deployment usulidan foydalanilsin.
